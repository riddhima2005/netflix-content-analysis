# Netflix Content Analysis using MySQL

## Project Overview

This project analyzes the Netflix titles dataset using MySQL to understand content distribution, ratings, genres, countries, release trends, and other key patterns.

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## Analysis Covered

* Movies vs TV Shows
* Content ratings
* Release year trends
* Top countries
* Popular genre combinations
* Average movie duration
* Directors with the most titles
* Netflix content additions over time
* SQL concepts including CASE, CTEs, subqueries, and JOINs

## Key Insights

* Movies make up 69.62% of the Netflix catalog.
* TV-MA and TV-14 are the most common ratings.
* 2018 had the most releases with 1,147 titles**.
* The US contributed the most titles, followed by India.
* Dramas, International Movies** is the most common genre combination.
* Average movie duration is about 100 minutes**.
* Rajiv Chilaka has the most titles among named directors with 19 titles.
* 2019 had the most Netflix additions with 2,016 titles.
* TV Shows have a newer average release year than Movies.
* The dataset contains titles released from 1925 to 2021.

## Dataset

Netflix Titles dataset containing information about movies and TV shows available on Netflix.
